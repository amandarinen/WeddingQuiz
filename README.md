# 💍 WeddingQuiz

An interactive wedding quiz created for a friend's wedding, designed to bring guests together through fun and personal questions about the couple.

## About the Project

WeddingQuiz is a web application developed as a personal project for a friend's wedding. The goal was to create a fun and interactive experience where wedding guests could participate in a quiz and test how well they know the couple.

The application was built from scratch using Blazor WebAssembly and MudBlazor, with a custom design and a soft, elegant color palette inspired by the wedding theme.

## Built With

- **C#**
- **.NET**
- **Blazor WebAssembly**
- **MudBlazor**
- **HTML & CSS**

## Features

- Interactive wedding quiz.
- Custom-designed user interface.
- Responsive layout.
- Wedding-inspired visual design.

## Getting Started

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/amandarinen/WeddingQuiz.git
   ```
2. Open `WeddingQuiz.sln` in Visual Studio.
3. Restore NuGet packages.
4. Run the application.
